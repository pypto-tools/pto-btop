# pto-btop v0.5.2

三台服务器的总览页面现在会用集群汇总填充第四个空位，提供 Linux amd64 / arm64 正式安装包。

## 总览改进

- 终端达到 120 列 × 36 行且配置三台服务器时，右下角自动显示 `cluster | overview`；沿用当前主题、边框和图表风格。
- 顶部显示在线服务器数、在线逻辑核心数、空闲 NPU 卡数和等待任务数，下方显示按逻辑核心数加权的 CPU 使用率与可用内存。
- 按原有服务器顺序对比 CPU、load/core 和空闲卡，较大窗口还显示 CPU 历史曲线与内存信息，方便选择负载较低的服务器。
- 汇总只计入在线且有效的数据；过期、维护或不可用的卡数据不计入空闲容量。底部显示采样覆盖率，部分数据标记 `*`，完全未知显示 `--`。
- 汇总面板不参与服务器选择，`Tab` 和数字键仍只选择真实服务器。快捷键提示按实际服务器数量显示。
- 新增 `--demo --demo-hosts 3`，可用模拟数据预览三台布局；一台、两台、四台和紧凑窗口继续使用原有布局。

## 升级

已完成共享服务安装的机器执行：

```bash
sudo pto-btop-update
# 访问 GitHub 需要代理时：
sudo pto-btop-update --proxy http://127.0.0.1:7892
```

更新后退出并重新打开 `pto-btop`。本次改进在查看端生效；协议、证书和节点配置继续复用，无需重新分发配置。各机器上的查看端需分别升级；系统更新命令也会按既有部署角色更新并重启本机服务。

仍使用用户目录安装的节点可从本次 Release 下载 `setup.py` 及其校验文件，在原配置目录运行。Linux 运行要求继续为 glibc 2.28+，包内静态链接 OpenSSL 和 GCC C++ runtime。
