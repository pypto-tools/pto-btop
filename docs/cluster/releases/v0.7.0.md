# pto-btop v0.7.0

SSH 和 HTTPS 监控的主机总数由接入配置决定。总览每页最多显示四台，所有主机持续采集。五台服务器会分成两页，第一页显示四台，第二页显示第五台。

## 查看主机

- 在总览用 PgUp／PgDn 翻页，按 1–4 打开当前页对应的主机详情，Esc 返回该页。也可输入 `#5` 后回车直接打开第五台。
- Tab／Shift+Tab 可跨页逐台选择。Home／End 选中第一台或最后一台。80×24 的紧凑总览使用同样的分页方式。
- 当前页有三台时，卡片布局右下角显示整个集群的汇总。卡时页的今日卡片对比当前页的主机，集群合计和用户表覆盖所有获授权主机。

在终端运行 `pto-btop --demo --demo-hosts 5` 即可预览。

## 升级和扩容

共享安装可在中心及运行查看端的机器上执行 `sudo pto-btop-update`，再重新打开 `pto-btop`。用户目录安装可下载本次发布的 `setup.py` 和校验文件，在原节点配置目录运行。现有节点沿用原来的证书、凭据和授权。

- SSH 模式为每台新主机追加一个 `--ssh 别名`。
- HTTPS 模式先升级中心和查看端。以后新增节点时，为其配置独立 agent 凭据，在 `server.json` 的 `hosts` 中登记，并把 ID 加入所需查看凭据的 `hosts` 列表。重启中心、启动新 agent，再打开查看端即可。用 `pto-btop --config /path/to/client.json --check` 可检查全部获授权主机。

Linux 安装包提供 amd64 和 arm64 两种架构，支持 glibc 2.28+，附 SHA-256 校验文件。回归测试覆盖五台和二十三台的终端翻页、七路模拟 SSH 连接的故障隔离，以及配置了 136 台主机的 HTTPS 中心按权限分批返回清单。
