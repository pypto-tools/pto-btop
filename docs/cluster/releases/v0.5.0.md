# pto-btop v0.5.0

正式版本，提供 Linux amd64 / arm64 安装包和支持代理的节点安装入口 `setup.py`。

## 新增功能

- 总览显示按登录账号去重的人数、会话数、可用卡数、运行任务和排队任务。
- 每张卡绘制一个带实际编号的芯片图标：占用红色、空闲灰色、预留黄色，禁用和未知带明确标记；8 卡、16 卡按空间自动换行。
- USERS、SESSIONS、RUNNING、WAITING 独立成框；RUNNING 只显示运行任务数，下方灰色 LIMIT 单独显示并发上限。
- 单机详情保留 CPU、MEM、DISKS、NET、PROC，新增 CARDS 表，查看占用者、当前预留、任务和持续时间。
- `u` 查看登录账号，`v` 切换卡表焦点，方向键选择卡，Enter 查看详情，`f` 按占用者 UID 精确筛选进程，`o` 折叠卡表。
- 进程过滤支持 `user:TEXT` 模糊用户名和 `uid:NUMBER` 精确 UID；各查看者的筛选互不影响。

## 数据与兼容性

agent 读取 Linux utmpx 登录记录，并在本机执行只读 `/usr/local/bin/task-submit --monitor --json`，要求 monitor schema 1。未安装组件、查询失败或数据过期时明确显示不可用，不推断空闲。卡状态表示队列分配，不表示硬件健康或新任务立即启动的保证。

基础负载默认每 2 秒采样。登录和卡信息每隔至少 5 秒采集，默认节拍下通常约 6 秒；磁盘容量约 10 秒。界面采用差分刷新。

新中心接受旧 agent；新 agent 遇到旧中心会回退为原基础指标。新增资源面板需要中心和目标 agent 均升级到本版本。

## 安装和升级

- amd64 对应 `x86_64`；arm64 对应 `aarch64`。
- 运行要求为 Linux glibc 2.28+；安装脚本需要 Python 3.10+，旧系统 Python 可通过 uv 使用 Python 3.12。
- 包内包含 `pto-btop`、`pto-btop-agent`、`pto-btop-server`；静态链接 OpenSSL 3.5.9 和 GCC C++ runtime，不要求系统安装 OpenSSL 3。
- 校验下载文件的 `.sha256`。已有节点在原配置目录下载新版 `setup.py` 和校验文件，运行 `python3 setup.py --restart-agent`；访问 GitHub 需要代理时追加 `--proxy http://127.0.0.1:7892`。
- 保留现有证书、令牌和节点配置。先升级并重启中心，再更新各 agent / TUI。`--restart-agent` 只重启该节点 agent，中心服务需单独重启。

源码版本 `0.5.0-alpha.1` 的功能经过本地预览后合入本次正式版，未发布对应预览包。
