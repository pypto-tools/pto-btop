# v0.5.0-alpha.1

- 总览新增登录账号／会话数、空闲卡数量和运行／等待任务数。
- 详情在 PROC 上方展示卡状态、占用者、当前预留和任务；`u` 查看登录账号，
  `v` 切换卡表焦点，Enter 查看详情，`f` 按占用者 UID 精确筛选进程，`o` 折叠卡表。
- agent 通过 Linux utmpx 和本地只读 `task-submit --monitor --json` 采集，
  超时／损坏／缺失／过期数据不宣称空闲，也不阻塞基础负载采样。
- 新中心兼容旧 agent；新 agent 对旧中心回退到基础指标。保留证书、令牌和节点配置。

升级时先更新并重启中心，再更新每台 agent 和终端。卡数据需要本机
`/usr/local/bin/task-submit` 支持 monitor schema 1。未更新节点的新字段显示 N/A。
卡状态反映队列分配，不代表硬件健康或承诺新任务立即启动。
