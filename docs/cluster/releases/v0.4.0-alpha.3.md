# pto-btop v0.4.0-alpha.3

Filter the process list by its owner: press `/`, enter `user:dev`, and
press Enter. This matches usernames containing `dev`, ignoring case; no wildcard is needed.
Plain text keeps the existing case-insensitive process-name search. Empty
`user:` matches nothing; clearing the whole filter restores all processes.

Filtering runs on the agent before sorting and applying the top-500 limit.
Each viewer and host keeps its own filter. Demo mode uses the same rules.

Upgrade and restart the agent on every host where user filtering is needed;
upgrading only the terminal is insufficient. The HTTPS protocol and enrollment
files are unchanged, and existing hubs remain compatible. No new credentials
or configuration distribution is required. Download this release's `setup.py`
into the existing enrollment directory and run it with `--restart-agent` to
activate the updated agent. The restart verifies a background process identity
with pidfd, or uses the existing user systemd service.

The amd64/arm64 packages retain the glibc 2.28 build baseline and bundled
OpenSSL 3.5.9. Installation requires Python 3.10+; uv can supply it.
