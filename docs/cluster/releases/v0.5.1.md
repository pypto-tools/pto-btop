# pto-btop v0.5.1

修复终端进程详情黑屏和卡列表翻页问题，提供 Linux amd64 / arm64 正式安装包。

## 修复

- 打开或切换进程详情时，保留现有进程列表、基本信息和历史曲线。等待新采样时显示 `[loading]`，不会把中心的临时空结果显示为整个 PROC 面板空白。
- 空进程列表不再打开 PID 0 或过时选择的详情。进程退出、详情不可用与等待采样分别显示明确提示。
- CARDS 的 PgUp/PgDn 按当前可见行数翻页，修复小窗口固定跳 8 张卡而跳过中间页的问题。
- 新增 `,` 上一页、`.` 下一页，自动展开 CARDS 并切换焦点。底边显示所选卡和页码，例如 `4/8 p2/3`。

## 升级

已完成共享服务安装的机器执行：

```bash
sudo pto-btop-update
# 访问 GitHub 需要代理时：
sudo pto-btop-update --proxy http://127.0.0.1:7892
```

更新后退出并重新打开 `pto-btop`。这些界面修复在查看端生效；协议、证书和节点配置沿用 0.5.0，无需重新分发配置。各机器上的查看端需分别升级；系统更新命令也会按既有部署角色更新并重启本机服务。

仍使用用户目录安装的节点可从本次 Release 下载 `setup.py` 及其校验文件，在原配置目录运行。Linux 运行要求继续为 glibc 2.28+，包内静态链接 OpenSSL 和 GCC C++ runtime。

## 验证

新增真实 HTTPS 与 PTY 回归覆盖详情加载过程不清空列表、空选择保护、卡表中间页、直接翻页和终端缩放；保留采集、权限隔离、断线恢复及安装升级检查。
